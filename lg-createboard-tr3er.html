Product Highlights

State-of-the-art features for seamless collaboration.

Google Certified (EDLA)

Seamlessly integrate with the Google ecosystem. Sync Google Drive, download native apps directly from the Google Play Store, and secure logins via Google account credentials.

50-Point Multi-Touch

Supports fluid multi-writing. A maximum of 50 touch points can be detected simultaneously, allowing multiple students or team members to write and collaborate at once.

LG CreateBoard Share

Wireless screen sharing for up to 4 devices simultaneously in real-time. Supports native AirPlay, Chromecast, and browser-based connection without dedicated apps.

LG ConnectedCare Cloud

Centralized device management solution. IT managers can remotely monitor status, adjust display brightness, schedule alerts, and broadcast emergency notices instantly.

Enterprise-Grade Security

Keep company files safe. Lock screens with secure PINs, restrict USB data copying with USB Lock Mode, and set files to delete automatically after a set period.

65W USB-C Connectivity

Establish single-cable loops. USB-C interface enables high-speed data transmission, screen casting, touch back control, and charging connected devices up to 65W.

LG CreateBoard Lab

Creative whiteboarding solution designed for fluid discussion.

LG CreateBoard Lab is a proprietary whiteboarding software suite built for real-time collaboration. It provides intuitive drawing, mapping, and media integration tools to facilitate engaging lessons and productive meetings.

Rich Annotation Tools Access digital pens, standard shapes, rulers, templates, mind maps, and sticky notes.
Integrated Web Browser Search the web, display online references, and drag-and-drop web images or links directly into the whiteboard canvas.
Easy Save & Share Save work files to Google Drive or OneDrive. Instantly send canvas summaries via email or scan a QR code to transfer to personal devices.

LG CreateBoard Share

Seamless wireless screen sharing for multi-device environments.

Allow presenters to cast screens effortlessly without cable clutter or physical reconnection. The LG CreateBoard Share application establishes a stable collaboration network supporting up to 4 real-time display projections.

App-Less Connection Cast screens natively using Apple AirPlay, Google Cast, or via a simple 6-digit PIN code on the browser website.
Multi-Screen View Display up to 4 presenter screens side-by-side. View documents, comparison sheets, and presentations simultaneously.
Secure Mode Protection Maintain display control. Prevent unauthorized castings by requiring moderator approval for incoming device streams.

ConnectedCare Cloud Management

Enterprise device fleet management, remotely optimized.

Reduce site visits and down-time. LG ConnectedCare is a robust cloud solution that enables IT administrators to monitor status, manage settings, and update firmware across all displays from a central location.

Real-time Status Dashboard Monitor system health, check app versions, track errors, and review active connection logs.
Emergency Broadcast & Alerts Instantly push warning notices or evacuation alerts across all classrooms or corporate floors during emergencies.
Remote Control Scheduling Schedule system power schedules, adjust brightness levels, and control screen settings remotely.

FAQs

Frequently Asked Questions

What Android version is the LG CreateBoard TR3ER equipped with?

The LG CreateBoard TR3ER series comes fully equipped with Android 16, which is Google EDLA certified, ensuring access to native Google apps and Play Store.

How many multi-touch points does it support?

The display features an advanced multi-touch point capacity supporting up to 50 simultaneous points, allowing multiple users to draw, annotate, and collaborate at the same time.

Does the TR3ER series have an OPS slot?

Yes, the TR3ER series includes a built-in Open Pluggable Specification (OPS) slot at the back. This allows users to easily slide in an OPS module to run a dedicated Windows PC setup without routing external cabinet cables.
