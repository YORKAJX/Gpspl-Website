# SEO Task 02 - Enterprise Keyword Map & Page Ownership

Date: 2026-07-28

## Purpose

This document defines the keyword architecture for GPSPL. It assigns one clear search intent to each important page so the site does not cannibalize itself.

This is not a list of random keywords. It is a page ownership map:

- One primary keyword per page
- Supporting keyword cluster
- Buyer intent
- Funnel stage
- CTA
- Internal links
- Content upgrade requirement

## Strategic Rules

1. One page owns one primary search intent.
2. Homepage should not try to rank for every service.
3. Money pages should target commercial buyer keywords.
4. Blog/FAQ pages should support research keywords.
5. Case studies should prove delivery and link back to money pages.
6. Location pages should be created only for real service areas.
7. Meta keywords are not a ranking lever; they are only a local planning aid. Real ranking comes from visible content, links, page quality and trust.
8. Avoid doorway pages and duplicate city pages.

## Primary SEO Positioning

GPSPL should be positioned as:

`Delhi NCR based AV and IT distribution, system integration and lifecycle support partner for enterprise meeting rooms, classrooms, auditoriums, LED walls, signage, control rooms and professional audio systems.`

This positioning should guide homepage copy, schema, service pages, internal linking and enquiry CTAs.
