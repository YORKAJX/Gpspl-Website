# SEO Task 03 - Homepage SEO & Conversion Rewrite

Date: 2026-07-28

## Goal

Upgrade the GPSPL homepage so it works harder for both search engines and real enterprise buyers, without turning the homepage into a bloated article.

The homepage now has three jobs:

1. Own the broad brand + AV integration positioning.
2. Promote the AV BOQ calculator as a serious planning tool.
3. Move buyers into the right service page or enquiry path quickly.

## Changes Made

### 1. Homepage H1 Repositioned

Old H1:

`We supply. We design. We integrate. We support.`

New H1:

`AV system integration for enterprise spaces.`

Reason:

The old line was strong branding, but weak for search intent. The new H1 gives Google and buyers a direct category signal while keeping GPSPL's professional positioning.

### 2. Hero Eyebrow Updated

New eyebrow:

`AV System Integrator & Technology Distributor Since 1997`

Reason:

This combines the two strongest GPSPL trust signals:

- AV system integration
- Technology distribution since 1997

### 3. Hero Copy Expanded Without Stuffing

The hero now mentions the real service scope:

- Conference rooms
- Boardrooms
- Classrooms
- Auditoriums
- LED walls
- Digital signage
- Professional audio
- IT infrastructure

Reason:

This helps buyers understand GPSPL quickly and supports homepage topical relevance.

### 4. CTA Stack Improved

New primary CTA:

`Build AV BOQ`

New secondary CTA:

`Explore AV Integration`

Phone CTA remains:

`Talk to an Expert`

Reason:

The homepage should push users into the strongest lead magnet first, then into the main money service page, then direct phone contact.

### 5. BOQ Calculator Static SEO Block Added

Added a crawlable explanation panel above the simulator:

- What the calculator does
- Who it is for
- What it estimates
- Site-survey disclaimer
- Internal links to key money pages

Reason:

The BOQ calculator itself is JavaScript-driven. Google and users still need a static explanation around it. This also strengthens keyword relevance for AV BOQ, conference room BOQ, professional audio, LED walls and installation scope.

### 6. Internal Links Added Around BOQ

The new BOQ explanation links to:

- `conference-room-solutions.html`
- `professional-audio-solutions.html`
- `active-led-wall-solutions.html`
- `amc-maintenance-services.html`

Reason:

This connects the homepage lead magnet to service-money pages and improves crawl paths.

### 7. Runtime Schema Messaging Synced

Updated `JS/seo.js` organization slogan and BOQ feature list so schema language matches the upgraded homepage positioning.

### 8. Enterprise Buyer Path Section Added

Added a compact homepage path section for buyers who enter with different needs:

- AV BOQ calculator
- Full AV integration
- Meeting rooms
- LED and display walls
- Professional audio

Reason:

This makes the homepage work like a conversion router instead of a generic brochure page. It also adds crawlable internal links to the top money pages without making the page feel stuffed.

### 9. Homepage FAQ Rewritten For AV Buyer Intent

Replaced generic homepage FAQ copy with buyer questions around:

- AV BOQ before site survey
- Conference room AV setup inclusions
- Installation and commissioning
- Planning range vs final pricing
- Existing AV/IT infrastructure
- Formal quotation process

Reason:

These questions support real search intent and help sales-qualified buyers understand the process before contacting GPSPL.

### 10. Homepage FAQ Schema Aligned

Updated homepage FAQ schema in `JS/seo.js` so structured data reflects visible homepage FAQ content.

Reason:

Schema should match visible content and should not be generic or disconnected from the page.
